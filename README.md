# 🎫 SysEvents - Frontend

Landing Page do Sistema de Gestão de Eventos (SysEvents) desenvolvida em React.js + TypeScript.

---

## 🚀 Tecnologias

- React.js
- TypeScript
- CSS3

---

## 📋 Requisitos atendidos

| Requisito | Descrição |
|-----------|-----------|
| JSX | Código TSX com HTML dentro do JS |
| Template Expressions | Uso de `{variavel}` no JSX |
| List/Keys | `map()` com `key={evento.id}` |
| useState | Estado do nome do usuário |
| Event Handling | `onChange` no input |
| Consumo de API | Busca eventos da API do SysEvents |

---

## 🛠️ Como rodar

```bash
npm install
npm start
